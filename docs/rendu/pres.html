  • 8 indicateurs de payment-api lus dans Prometheus : req/s, 5xx, latence p95, CPU, RAM, SQL actif…

  • Isolation Forest + enveloppe statistique : l'Isolation Forest seul saturait à 0,506 sous une charge à 120 σ.

Un moteur puissant, mais bridé : jamais de socket Docker brut (proxy limité à restart / kill), aucun port publié, WAF rechargé par fichier + signal. Si une action échoue, escalade vers l'action suivante puis vers l'opérateur.
RESILIENCE-ALPHA
Quand l'alerte arrive, le remediator cherche dans les journaux du WAF qui envoie le plus de requêtes, le bannit, redémarre le service si nécessaire, puis rejoue une vraie transaction. Ce n'est qu'à ce moment qu'il déclare la reprise. Le moteur a des droits sur les conteneurs, donc on les a limités au strict nécessaire.

RESILIENCE-ALPHA
Côté cybersécurité : un WAF en mode blocage, une fonction SOC dans Grafana, des secrets chiffrés avec SOPS, un cloisonnement réseau strict et des conteneurs durcis. L'assistant RAG local, lui, ne fait que lire la documentation : il n'a aucun droit sur le système.
